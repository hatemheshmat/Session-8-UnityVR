Session 8 Assignment

Tasks to complete for next week

VR Mini-Projects Enhancement
Extend and improve the Basketball Grab and Tic-Tac-Toe projects
Basketball Grab Enhancements
  1. Add a timer system that gives players 60 seconds to score as many baskets as possible.
  2. Implement a combo system that gives bonus points for consecutive successful shots.
  3. Create a distance multiplier that awards more points for shots made from further away.
  4. Add visual effects (particle systems) when a basket is scored.
Bonus Challenge
Implement a moving hoop that changes position after each successful shot, making the game progressively more challenging.
Tic-Tac-Toe Enhancements
  1. Add a simple AI opponent that can play against the player (doesn't need to be unbeatable).
  2. Implement 3D models for X and O pieces instead of using basic cubes.
  3. Add animation and sound effects when placing pieces and when a player wins.
  4. Create a game statistics panel that tracks wins, losses, and draws across multiple games.
Bonus Challenge
Implement a 4×4 grid version of the game with modified win conditions (4 in a row required to win).
Code Organization
  1. Ensure your code follows proper naming conventions and includes comments explaining key functionality.
  2. Organize your project with a clean hierarchy and appropriate prefabs for reusable components.
  3. Implement proper error handling to prevent null reference exceptions and other common issues.
Submission Requirements
Submit your Unity project as a compressed ZIP file containing your entire project folder. Include a brief README.txt file explaining which enhancements you implemented and any known issues.
Due: One week from today
