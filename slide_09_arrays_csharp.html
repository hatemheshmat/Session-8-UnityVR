Arrays in C#

Using arrays to store game state for Tic-Tac-Toe

Array Basics

Arrays are collections of elements of the same type with a fixed size. They're perfect for storing game state data like our Tic-Tac-Toe board.

// Declaring a 1D array
int[] scores = new int[5]; // Array of 5 integers

// Initializing with values
int[] scores = new int[] { 10, 20, 30, 40, 50 };

// Accessing elements (zero-indexed)
int firstScore = scores[0]; // 10
int thirdScore = scores[2]; // 30

// Modifying elements
scores[1] = 25; // Changes 20 to 25

// Getting array length
int length = scores.Length; // 5

2D Arrays for Tic-Tac-Toe

For our Tic-Tac-Toe game, we'll use a 2D array to represent the 3×3 game board.

// Declaring a 2D array for Tic-Tac-Toe
int[,] board = new int[3, 3];

// Initialize with values (0=empty, 1=X, 2=O)
int[,] board = new int[,] {
    { 0, 1, 2 },
    { 0, 1, 0 },
    { 2, 0, 0 }
};

// Accessing elements
int centerValue = board[1, 1]; // Value at row 1, col 1

// Modifying elements
board[0, 2] = 1; // Place X at top-right

// Getting dimensions
int rows = board.GetLength(0); // 3
int cols = board.GetLength(1); // 3

// Example: Checking for a win in a row
bool CheckRowWin(int player)
{
    for (int row = 0; row < 3; row++)
    {
        if (board[row, 0] == player && 
            board[row, 1] == player && 
            board[row, 2] == player)
        {
            return true;
        }
    }
    return false;
}
