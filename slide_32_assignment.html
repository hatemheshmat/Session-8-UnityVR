Session 8: Basketball Grab Mini-Project (Part 2) & VR Tic-Tac-Toe

Session 8 Assignment

Enhanced Basketball Game & Tic-Tac-Toe Implementation

Project Overview

Complete two VR mini-games: enhance the Basketball Grab project with scoring and sound effects, and implement a fully functional Tic-Tac-Toe game using arrays and game state management.

Requirements

Technical Requirements

  • Unity 6 with Meta XR All-in-One SDK
  • Proper implementation of arrays and game states
  • TextMeshPro for all UI text elements
  • World-space canvas for UI elements
  • Audio feedback for game events
  • Proper controller velocity calculation

Tasks

  • Implement throw velocity calculation for basketball
  • Create hoop trigger and scoring logic
  • Add sound effects for successful shots
  • Implement ball reset mechanism
  • Create 3x3 Tic-Tac-Toe board in VR
  • Implement array-based game state tracking
  • Create win detection algorithm
  • Add visual/audio feedback for game events
  • Implement "New Game" button functionality
  • Add game state transitions (menu, playing, game over)

Submission

Submission Guidelines

Submit as .zip with all project files, README.md, and demo video (30-60s)

Due: August 25, 2025 at 11:59 PM
